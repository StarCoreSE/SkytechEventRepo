# AriUtils
Utility shared project for Space Engineers. Ari says hi.

---

# Basic Usage
| Class                             | Purpose                                                                                                                                                                                                                     | Usage                                                                                                                                                                                                                                                                                                                                                                              |
|-----------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `BlockCategoryManager`            | Creates a GUI block category for all blocks in your mod.                                                                                                                                                                    | Instantiate in your partial `ClientMain` as per `SingletonBase`.                                                                                                                                                                                                                                                                                                                   |
| `CleanedSet` & `CleanedList`      | `ICloseable` Collection that removes closed items when `(CleanedCollection).Update()` is called.                                                                                                                            | Use the collection as you normally would, invoke `Update()` when safe.<br>`ICloseable` classes have an IsClosed property that is checked during update.                                                                                                                                                                                                                            |
| `ClientNetwork` & `ServerNetwork` | Networking singletons that send and receive bulk packets.                                                                                                                                                                   | Set a network ID in `GlobalData`! These are otherwise automatically instantiated by `ClientMain` and `ServerMain`.<br>All packets must inherit from `PacketBase`, and have a `ProtoInclude` tag on `PacketBase`.<br>Include a partial `PacketBase` in your mod with your `ProtoInclude` tags as needed.<br>`GetInfo` should be overridden for the `NetworkProfiler` to work right! |
| `DebugDrawManager`                | Provides debug shape draw functionality. Is a SessionComponent because lazy.                                                                                                                                                | See class for details.                                                                                                                                                                                                                                                                                                                                                             |
| `GlobalData`                      | Generic partial mod-wide data class. Provides logging, helpful cached data, and networked `IniConfig`.                                                                                                                      | Include a partial `GlobalData` in your mod with the following set:<br>- `FriendlyModName`<br>- `public static readonly string LastBuildTime = "$MDK_DATETIME$";`<br>- Unique `ServerNetworkId`, `DataNetworkId`, and `ClientNetworkId`<br>- `KillswitchCheck` (i.e. `modIdFormatted => modIdFormatted.Contains("skytech engines")`)                                                |
| `IniConfig`                       | Config generator using the INI format.                                                                                                                                                                                      | In your class, include a `new IniConfig(location, fileName, sectionName, sectionComment)` field for every config section.<br>Invoke `ReadSettings()` and `WriteSettings()` as needed; they are not automatically called.<br>For each config field, include a `new IniConfig.IniSetting<TValue>(config, name, description, value, optional onChanged)` field in your class.         |
| `Log`                             | Log writer that outputs to console and a text file in global storage.<br>Provides a safe custom crash window on fatal exception or rapid non-fatal exceptions.<br>Initialized and updated by `GlobalData`.                  | `Info(source, message)` logs a generic message.<br>`Exception(source, exception, fatal=false)` logs an exception; if fatal is true, the game crashes during the next tick.<br>`IncreaseIndent()` & `DecreaseIndent()` controls the indentation level of the log.                                                                                                                   |
| `NetworkProfiler`                 | Profiles sent and received packets and their fields. Can retrieve results from the server as a client.                                                                                                                      | See class for details.                                                                                                                                                                                                                                                                                                                                                             |
| `ObjectPool`                      | Provides a thread-safe shared pool of objects with factory and cleanup methods.<br>Particularly useful for avoiding expensive collection allocation.<br>`(AsyncSharedObjectPool).Pop()` returns one unique object per tick. | Instantiate with the primary constructor in an accessible location; the more places the pool is used, the better.<br>`Pop()`<br> retrieves an object from the pool, or creates a new one if none are available.<br>`Push()`<br> returns an object to the pool and invokes the cleanup delegate.                                                                                    |
| `SessionInstance`                 | Base class for Singleton container sessioncomponents.<br>Includes Client, Server, and Shared partial classes inited by default.                                                                                             | Copy relevant partial classes into your mod assembly and init singletons as fields or as needed.                                                                                                                                                                                                                                                                                   |
| `SingletonBase`                   | Base class for Singletons inited by `SessionInstance`s.<br>Provides automatic init, update, and close functionality.                                                                                                        | Instantiate new singletons by static calling `(YourType).CreateWithOwner<OwnerType>();` at any time.<br>Avoid calling this method multiple times per session.                                                                                                                                                                                                                      |
